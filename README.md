# Excel Clone 🧮

A web-based clone of Microsoft Excel, built from scratch using HTML, CSS, and JavaScript. This project emulates core spreadsheet features including cell editing, formatting, multi-sheet support, and more—directly in the browser.

## 🔧 Features

- Grid layout with resizable cells and columns  
- Multi-sheet support  
- Formula parsing and evaluation  
- Rich text formatting (bold, italic, underline, etc.)  
- Cut, copy, paste, undo, and redo functionality  
- File saving and loading using JSON  

## 💡 Technologies Used

- HTML5  
- CSS3  
- Vanilla JavaScript (ES6+)  
- LocalStorage for file persistence
